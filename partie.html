Une partie de Devinons, le quiz en famille, est lancée sur un autre téléphone.

Code de la partie

  1. Installez Devinons (gratuit).
  2. Sur l'accueil, touchez « Rejoindre une partie lancée sur un autre téléphone ».
  3. Scannez le QR code ou saisissez le code.
